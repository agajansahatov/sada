# SADA (React + TypeScript)

SADA is now reimplemented as a React + TypeScript dashboard with plain CSS and no jQuery/Bootstrap runtime dependencies.

## What's included

- React component architecture for dashboard shell, sidebar, and topbar.
- Type-safe layout mode switching for the 7 original layout concepts:
  - Content overlay
  - Fixed partially collapsing
  - Animated
  - Fixed
  - Fixed animated
  - Simple
  - Top navigation
- Pure CSS styling and animations.

## Development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```
